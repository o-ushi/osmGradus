# レイヤーⅠ「語彙を増やす」単語テスト 実機確認手順

自動テスト（`flutter test`）はネイティブの録音・音声認識・TTS・クリップボード・
外部ブラウザ起動を実際には実行できない（widget test はプラットフォーム
チャンネルをモックしている）。そのため、以下の手順は**実機**
（iOS実機 / Android実機）で必ず一度は確認すること。

## 前提条件

- iOS/Android共通：実機にビルドして起動できる状態。マイク権限・音声認識
  権限が未許可の状態から始められるとなお良い（初回許可ダイアログの確認）。
- Chrome（またはOSの既定ブラウザ）がインストール済みで、Googleアカウントで
  ログイン済み（AIモード検索を使うため）。
- 単語帳にN1/N2/N3いずれかのレベルで語が入っていること
  （既定では標準JLPT語彙が各20語含まれる。オフにしている場合は「＋」で
  Chrome AI取り込みか、設定で標準語彙をオンにする）。

## 0. Chrome AI 語彙取り込み（「＋」）

1. 単語テスト画面の「＋」をタップすると「語彙の取り込み」画面が開く。
2. 「Chrome AI で開く」→ Google AIモードでN1/N2/N3各20語のJSONが生成される。
3. 回答をコピーしてアプリに戻り、自動読み込み（または「クリップボードから読み込む」）
   → プレビュー確認 →「取り込む」で単語帳に追加される。
4. レベル別件数と、追加した語の削除ができること（標準JLPT語彙は削除されないこと）。

## 0b. モード切替・MiniPlayer

1. 語彙画面の「モード選択に戻る」で2択に戻ること。
2. 耳慣れ画面でも同様。ヘッダー「Ⅰ」再タップでも2択に戻ること。
3. MiniPlayerは耳慣れのときだけ表示され、語彙・2択では出ないこと。

## 1. レベル選択・出題・TTS読み上げ

1. レイヤーⅠ→「語彙を増やす」で単語テスト画面を開く。
2. 「レベル」をタップし、N1/N2/N3/ランダムを切り替えられることを確認する。
   ランダムはN1/N2/N3のみが対象で、レベル未指定（その他）の語は出ないこと。
3. サイコロをタップすると、選択レベルの単語帳から1語抽選してカードに表示し、
   その読み（無ければ単語そのもの）がTTSで読み上げられ、ボタンがマイク
   （背景透明）に変わることを確認する。
4. カード左上に「1 / 10」のような進捗表示が出ることを確認する。
5. 表示offボタン（👁️）で単語の文字が隠れ、ヘッドフォンアイコンと案内文に
   置き換わること（聞き取りのみのモード）を確認する。表示offのままでも
   TTS読み上げと録音は通常どおり行えることを確認する。
6. 👁️の右隣の回答言語ボタンが既定で🇻🇳になっていることを確認する。
   タップするたびに🇻🇳→🇺🇸→🇯🇵→🇻🇳…と巡回すること。

## 2. 回答言語ごとの音声認識（★実機でのみ確認可能・最重要）

このセクションは自動テストで検証できない（widget testはネイティブの音声
認識プラットフォームチャンネルを呼ばない）ため、**実機で必ず確認すること**。
レイヤーⅣ/Ⅴの音声認識は常に日本語固定だが、単語テストだけは回答言語
ボタンで選んだ言語のロケールで音声認識するよう切り替わる。

1. 回答言語を🇻🇳にした状態でサイコロ→マイクをタップし、単語の訳をベトナム語
   で口頭回答する。文字起こし結果（📖の隣の「語彙力評価結果」→該当記録の
   詳細、またはリセット前に単語帳を開いて確認）がベトナム語として正しく
   認識されていることを確認する（日本語として誤認識された不自然な文字列に
   なっていないこと）。
2. 回答言語を🇺🇸に切り替え、同様に英語で口頭回答し、英語として正しく
   認識されることを確認する。
3. 回答言語を🇯🇵に切り替え、日本語で口頭回答し、従来通り日本語として
   認識されることを確認する（レイヤーⅣ/Ⅴと同じ挙動に戻ることの確認）。
4. Android実機では、オンライン認識が失敗した場合に日本語Voskモデルへ
   フォールバックする既存の仕組みがあるが、回答言語が🇻🇳/🇺🇸のときは
   このフォールバックを行わない（誤認識を避けるため）。電波の悪い環境等で
   オンライン認識が失敗した場合、🇻🇳/🇺🇸では「うまく聞き取れませんでした」
   の案内になり、🇯🇵のときだけ従来通りVoskフォールバックが動くことを
   確認できるとなお良い（再現性が低いためベストエフォート）。

## 3. 録音（タップで開始・タップで終了）

1. マイク（背景透明）をタップし、初回はOSのマイク権限ダイアログが出ることを
   確認する。「許可」を選ぶ。
2. 録音中はボタンの背景が赤に変わることを確認する。単語の訳をベトナム語
   または英語で口頭回答し、赤いマイクをもう一度タップして録音を終了する。
3. 文字起こし後、サイコロに戻り、STT結果は特に表示されない
   （次にサイコロをタップするまで、単語帳📖ボタンやリセットで確認できる）
   ことを確認する。
4. ▶︎ボタンで直前の録音を再生できることを確認する。
5. わざと無言のまま録音・停止し、「うまく聞き取れませんでした」の案内が
   出ること、それでもサイコロに戻り次の問題へ進めることを確認する。
6. マイク権限を設定アプリ側で「許可しない」に変更した状態でマイクを
   タップし、クラッシュせず「マイク権限なし」等の案内が出て、マイクの
   構えのまま留まることを確認する（権限拒否時の安全な処理）。
7. リセットボタンをタップすると、試験が最初からやり直せる状態
   （サイコロ・単語未出題・進捗表示なし）に戻ることを確認する。
8. サイコロをタップして単語を出題中に📖（単語帳）をタップすると、単語帳が
   その単語のカードを直接開いた状態で表示されることを確認する。

## 4. 全10問回答・Chrome AIへの送信

1. 10問すべてに回答する（プールが10語未満のレベルでは、そのプールの
   語数分で完走する）。最後の問題に回答すると、マイクボタンが非表示になり、
   代わりに送信（✈️）アイコンが表示されることを確認する。
2. 送信アイコンをタップし、送信内容の確認ダイアログで「同意してGoogleへ
   送信」を選ぶ。
3. Chrome（既定ブラウザ）がGoogleのAIモード検索で開き、プロンプトに
   10問分の「word / reading / expectedTranslation / learnerAnswer」と、
   各問の正誤＋総合1〜5点で評価する指示、固定JSON形式の出力フォーマットが
   含まれていることを確認する。**録音した音声ファイルそのものはどこにも
   添付・送信されていないこと**（プロンプトはテキストのみ）を目視で確認する。
4. AIの回答をコピーする。
5. アプリに戻る（Android: バックグラウンドキープアライブにより、戻ってきた
   ときにプロセスが落ちていないこと）。
6. 送信アイコンが緑色の貼り付けアイコンに変わっていることを確認する。

## 5. 貼り付け・結果表示・保存

1. 貼り付けアイコンをタップする。
2. その場で結果ダイアログが開き、以下が表示されることを確認する。
   - 総合評価の★表示（1〜5個）
   - 正解数（例：「正解 7 / 10問」）
   - 全体講評（あれば）
   - 各問の単語・正誤アイコン・簡単なフィードバック
3. 「完了」で閉じられること、閉じたあとは送信アイコンも貼り付けアイコンも
   非表示（ゴースト）に戻ることを確認する。
4. 同じ貼り付け操作を連続で素早く2回タップしても、保存されるのは1件だけ
   であることを確認する（二重保存防止）。
5. Chrome側でコピーし忘れた／空のクリップボードのまま貼り付けアイコンを
   押すと「Chrome AIの解析結果を読み取れませんでした」等の案内が出て
   クラッシュしないことを確認する。
6. AIの回答が崩れたテキスト（JSON以外の文章のみ等）の場合でも、
   「Chrome AIの回答を解析できませんでした」の案内が出て、クラッシュせず
   その場では未解析のまま保存だけは完了することを確認する。

## 6. リセットでの再試験

1. 10問完走・送信・貼り付け保存まで終えた状態からリセットをタップすると、
   新しい試験（セッション未生成の状態）に戻り、再度サイコロから10問を
   やり直せることを確認する。
2. Chrome AI送信後・貼り付け待ちの途中でリセットした場合も、貼り付け待ち
   状態が解除され、送信アイコンの通常表示に戻ることを確認する。

## 7. Android/iOS固有の確認

- Android: Chrome往復中にアプリがバックグラウンドキープアライブで
  落ちないこと。
- iOS: マイク・音声認識の許可ダイアログが初回のみ出ること。TTS読み上げと
  録音直後の▶︎（聞き直し）再生がバッティングしないこと。
