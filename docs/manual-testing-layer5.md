# レイヤーⅤ（発音チェック）実機確認手順

自動テスト（`flutter test`）はネイティブの録音・音声認識・クリップボード・
外部ブラウザ起動を実際には実行できない（widget test はプラットフォーム
チャンネルをモックしている）。そのため、以下の手順は**実機**
（iOS実機 / Android実機。シミュレータ・エミュレータではマイク入力や
音声認識が正しく動作しないことがあるため、可能な限り実機で確認する）
で必ず一度は確認すること。

## 前提条件

- iOS: 実機にビルドして起動できる状態（`flutter run` または Xcode 経由）。
  設定アプリでマイク権限・音声認識権限が未許可の状態から始められるとなお良い
  （初回許可ダイアログの確認のため）。
- Android: 実機にビルドして起動できる状態。マイク権限が未許可の状態から
  始められるとなお良い。
- 両OSともChrome（またはOSの既定ブラウザ）がインストール済みで、
  Googleアカウントでログイン済み（AIモード検索を使うため）。
- 日本語入力キーボード等は不要。クリップボードのコピー＆ペーストが
  できれば良い。

## 1. 起動画面・ヘルプの文言確認

1. アプリを起動し、起動画面のレイヤーⅤタイル説明文を確認する。
   「短文／長文で発音のクセを確認しよう」（vi/en設定でもそれぞれの訳文）が
   表示され、「AIが音声を直接判定する」ように読める表現になっていないこと。
2. レイヤーⅤを開くと「短文」「長文」の2択が出ること。長文一覧が空のときは
   「長文」がグレーアウトされ、レイヤーⅠで作成する案内が出ること。
3. ヘルプ（起動画面右上などから）を開き、レイヤーⅤのセクションを確認する。
   Tipが短文/長文の選択・10問読み上げ／送信はテキストのみで
   音声は送信しない旨／貼り付けで★評価とアドバイスを保存／録音モード切替に
   なっていること。
4. 設定言語を 日本語 → English → Tiếng Việt と切り替え、起動画面・ヘルプの
   レイヤーⅤ文言が崩れずに翻訳表示されることを確認する。

## 2. 10問セッションの開始・出題

1. レイヤーⅤで「短文」を選ぶ。初期状態はサイコロのアイコンで、問題文はまだ表示
   されていないこと（「サイコロをタップして問題を表示」の案内が出ている）。
2. サイコロをタップすると、進捗表示が「1 / 10」になり、対象カテゴリ
   （「つ」「ざ・ず・ぞ」ラ行／長音／促音のいずれか）・日本語短文・かな読み・
   ベトナム語ヒントが表示され、ボタンのアイコンがマイク（背景透明）に
   変わることを確認する。
3. このレイヤーには読み上げ（TTS）機能はない。問題文を目で読んで発音する。

## 3. 録音（タップで開始・タップで終了）

1. マイク（背景透明）をタップし、初回はOSのマイク権限ダイアログが出る
   ことを確認する。「許可」を選ぶ。
2. 録音中はボタンの背景が赤に変わることを確認する。短文をはっきり声に
   出して読み上げ、赤いマイクをもう一度タップして録音を終了する。
3. 文字起こし中の進捗表示（プログレスバー／フェーズ文言）が出ることを
   確認する。完了後、**サイコロを経由せず自動的に次の問題（2 / 10）が
   表示され、ボタンは背景透明のマイクに戻っている**こと（＝すぐ次の
   録音を開始できる状態）を確認する。
4. 直前の問題のSTT結果は、次の問題が表示されている間もカードの下に
   残っていることを確認する（回答内容の確認用）。
5. ▶︎ボタンで直前の録音を再生できることを確認する
   （just_audioでの自分の声の聞き直し）。
6. わざと無言のまま録音・停止し、「うまく聞き取れませんでした」の案内が
   出ること、それでも自動的に次の問題へ進むことを確認する
   （STT空結果の安全な処理）。
7. マイク権限を設定アプリ側で「許可しない」に変更した状態でマイクを
   タップし、クラッシュせず「マイク権限なし」等の案内が出て、マイクの
   構えのまま留まる（サイコロに戻らず、もう一度タップして再試行できる）
   ことを確認する（権限拒否時の安全な処理）。
8. リセットボタンをタップすると、新しい10問セッションが抽選され、
   サイコロの初期状態に戻ることを確認する。

## 4. 全10問回答・Chrome AIへの送信

1. 10問すべてに回答する（上記の録音手順を10回、または一部は無言回答も
   交えて）。10問目を録音・終了すると、これ以上進む問題がないため
   マイクボタンごと非表示になり、代わりに送信（✈️/送信アイコン）が
   表示されることを確認する。
2. 送信アイコンをタップし、送信内容の確認ダイアログで「送信」を選ぶ。
3. Chrome（既定ブラウザ）がGoogleのAIモード検索で開き、プロンプトに
   10問分の「category / sentence / reading / targetExpressions /
   deviceTranscript」と、5カテゴリを1〜5点で評価する指示、固定JSON形式の
   出力フォーマットが含まれていることを確認する。
   **録音した音声ファイルそのものはどこにも添付・送信されていないこと**
   （プロンプトはテキストのみ）を目視で確認する。
4. AIの回答をコピーする（回答を長押し→すべて選択→コピー）。
5. アプリに戻る（Android: バックグラウンドキープアライブにより、
   戻ってきたときにプロセスが落ちていないこと。iOS: 通常のApp Switcher
   復帰で問題ないこと）。
6. 送信アイコンが緑色の貼り付けアイコンに変わっていることを確認する。

## 5. 貼り付け・プレビュー・保存

1. 貼り付けアイコンをタップする。
2. 保存前プレビューダイアログが開き、以下が表示されることを確認する。
   - 「STT結果に基づく参考評価です（音声そのものは判定していません）。」の
     明示（**「AIが音声を直接判定した」という誤解を招く表現がないこと**）
   - 5カテゴリそれぞれの★評価（1〜5個）
   - カテゴリごとのフィードバック（言語設定に応じた1言語。旧形式データの
     場合は日本語・ベトナム語併記）
   - 全体講評
   - 最低スコアのカテゴリに基づく改善アドバイス文
3. 「保存」をタップし、ダイアログが閉じてボタンが再度非表示になることを
   確認する。
4. 同じ貼り付け操作を連続で素早く2回タップしても、保存されるのは
   1件だけであることを確認する（履歴一覧の件数で確認、二重保存防止）。
5. Chrome側でコピーし忘れた／空のクリップボードのまま貼り付けアイコンを
   押すと「Chrome AIの解析結果を読み取れませんでした」等の案内が出て
   クラッシュしないことを確認する。
6. AIの回答が崩れたテキスト（JSON以外の文章のみ等）の場合でも、
   プレビューに「AIの回答を解析できませんでした。貼り付けた内容を
   そのまま保存しますか？」の確認とAI回答原文が表示され、「保存」を
   押すと（未解析のまま）保存できることを確認する。

## 6. 履歴一覧・詳細画面

1. レイヤーⅤの「発音チェック結果」アイコンから履歴一覧を開く。
2. 保存した記録に、実施日時・改善の重点カテゴリ・5カテゴリの★が
   1行で表示されていることを確認する。
3. その記録をタップして詳細画面を開き、以下が表示されることを確認する。
   - 出題した10問（各文とカテゴリ）
   - 各問題ごとの端末STT結果（未回答・認識できなかった場合の案内も含む）
   - 5カテゴリの評価（★・日本語/ベトナム語フィードバック・全体講評・
     改善アドバイス、および参考評価の明示）
   - AI回答原文（貼り付けたテキストそのまま）
4. 左スワイプで削除できること、削除確認ダイアログが出ることを確認する。

## 7. 旧形式データの閲覧（アップグレード前のデータがある場合）

以前のバージョン（自由発話・自由記述のみを保存する形式）で保存した
発音チェック結果がある端末では：

1. 履歴一覧にその記録が「旧形式」バッジ付きで表示されることを確認する。
2. タップした詳細画面でも「旧形式」バッジと「旧形式のデータです」の説明、
   および元の自由記述テキストがそのまま表示されることを確認する
   （データが失われていないこと）。

## 8. 発音課題の取り込み（レイヤーⅡと同様のChrome AI連携）

1. レイヤーⅤの「発音課題を取り込む」アイコンから取り込み画面を開く。
2. 「Chrome AIで開く」でプロンプトが送られ、5カテゴリ×5文（計25文）の
   JSON生成を依頼する内容になっていることを確認する。
3. AIの回答をコピーしてアプリに戻り、自動または手動で読み込む。
4. 取り込み前にプレビュー一覧（カテゴリ・文・読み）が表示されることを
   確認する。
5. 「取り込む」をタップし、カテゴリ別の件数が増えることを確認する。
6. カテゴリ別の削除ボタンで、そのカテゴリの取り込み済み課題だけが
   削除され、組み込みの5問（各カテゴリ）は消えずに残ることを確認する。
7. 取り込み後にレイヤーⅤでセッションを開始し直すと、取り込んだ課題も
   抽選対象に含まれうることを確認する（複数回セッションを開始して
   取り込んだ文が出題されるかを確認する）。

## 9. Android固有の確認

- Chrome往復中にアプリがバックグラウンドキープアライブで落ちないこと。
- 端末STT（オンライン認識→Voskオフラインフォールバック）が初回はモデル
  ダウンロードの進捗表示を伴うことがある点を確認する。

## 10. iOS固有の確認

- マイク・音声認識の許可ダイアログが初回のみ出ること。
- 録音直後の▶︎（聞き直し）再生とバッティングしないこと
  （`.playAndRecord`カテゴリでの音声セッション切り替えが正しく動作すること）。
