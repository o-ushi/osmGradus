# osmGradus プライバシーポリシー

最終更新日：2026年11月11日

「osmGradus」（以下「本アプリ」）は、以下のとおり利用者情報を取り扱います。本アプリの開発者は、独自のサーバーを運営しておらず、広告・行動分析・クロスアプリトラッキングを行いません。

## 1. 本アプリが取り扱うデータ

本アプリは、ユーザーの操作に応じて次のデータを端末内で取り扱います。

- 録音音声、音声認識による文字起こし
- 発話の採点結果、発音評価、AIから取得した回答
- ユーザーが登録した単語、練習課題、問題文、長文、問題文ごとの記入内容（要約・PREP等）
- 単語テストでのキーボード入力による回答
- Podcastの検索語、登録URL、番組情報、再生位置
- 言語、読み上げ、外観などのアプリ設定
- 音声認識処理の状態を示す診断ログ（認識本文は含みません）

氏名、住所、メールアドレス、電話番号、連絡先、位置情報をプロフィール情報として要求することはありません。ただし、ユーザーが録音した発話や文字起こしには、ユーザー自身が話した氏名その他の個人情報が含まれる場合があります。

## 2. 録音と音声認識

発音練習および発話採点では、ユーザーがマイク操作または練習タイマーを開始した場合に録音します。録音音声を文字起こしするため、iOSではApple Inc.のSpeech Recognition、Androidでは端末に設定された音声認識サービスへ音声を渡します。

端末、OS、言語、ユーザー設定によっては、録音音声がAppleまたは端末の音声認識事業者のサーバーへ送信され、クラウド上で処理される場合があります。Androidでオンライン認識を利用できない場合は、端末内のVoskモデルで処理します。

本アプリは、音声認識を初めて利用する前に、送信されるデータ、送信先および目的をアプリ内で説明し、ユーザーの明示的な同意を取得します。同意しない場合も、音声認識を使わない機能は利用できます。同意は「設定 > プライバシーとデータ」から撤回できます。

Appleのデータ取扱いは [Appleプライバシーポリシー](https://www.apple.com/legal/privacy/) をご確認ください。Androidの音声認識については、端末に設定された音声認識事業者のプライバシーポリシーが適用されます。

## 3. Google AIモードへの送信

本アプリには、開発者が運営するAIサーバーや独自のAI APIはありません。以下の機能でユーザーが希望した場合に限り、Google LLCが提供するGoogle検索（AIモード）を外部ブラウザで開き、参考評価・アドバイス・教材の作成を依頼します。

### 3-1. 練習結果の評価・アドバイス（ユーザーの回答を含みます）

| 機能 | 送信するデータ | 目的 |
|---|---|---|
| レイヤーⅤ 発音チェック（短文10問） | 10問の問題文、読み、評価対象の発音表現、各問題に対する発話の文字起こし | 発音上の傾向（「つ」・ざ行・ラ行・長音・促音、リズム、音の脱落）に関する参考評価 |
| レイヤーⅤ 長文音読 | 長文の冒頭抜粋、音読の文字起こし（冒頭の一部） | 同上 |
| レイヤーⅤ 問題文への回答 | 問題文、回答の文字起こし | 同上 |
| レイヤーⅠ 単語テスト | 出題した単語、読み、ユーザーの回答（発話の文字起こし、またはキーボード入力） | 語彙力に関する参考評価 |
| レイヤーⅣ PREP評価・的中度 | 問題文、回答の文字起こし | 回答の構成（PREP）と、問題文への答え方の的確さに関する参考評価 |
| 問題文の総評 | 問題文と、その問題文についてレイヤーⅠ〜Ⅴで記入・記録した内容（登録した単語、要約、結論・理由・例示、各レイヤーのスコア等） | 問題文ごとの総合アドバイス |
| ダッシュボード | 直近最大3件ずつの、レイヤーⅣの採点結果（文字起こし、参考レベル、的中度、PREP等）、レイヤーⅤの発音チェック結果（カテゴリごとのスコア、講評等）、レイヤーⅠの単語テスト結果 | 練習全体の総合アドバイス |

いずれの機能でも、録音音声そのものはGoogleへ送信しません。ただし、文字起こしやキーボード入力、記入内容には、ユーザーが話した・書いた氏名その他の個人情報が含まれる可能性があります。

### 3-2. 教材の作成（ユーザーが選んだ文章・語を含みます）

| 機能 | 送信するデータ | 目的 |
|---|---|---|
| レイヤーⅠ 問題文からの単語抽出 | 問題文 | 語彙テスト用の単語の抽出 |
| レイヤーⅡ・Ⅳ 解答例 | 問題文 | 約45秒で話せる解答例の作成 |
| レイヤーⅤ 問題文に関連した発音練習文 | 問題文 | 発音練習用の短文の作成 |
| 長文読解の生成 | ユーザーが入力したキーワード、JLPTレベル、文体、目安の文字数 | 読み物の作成 |
| 長文読解の訳付け | ユーザーが選択した単語 | 読み・訳・例文の取得 |

問題文には、アプリに収録された問題文のほか、ユーザーが追加・編集した問題文が含まれます。

### 3-3. 送信の方法と同意

いずれの送信も、上記のデータに回答言語および出力形式の指示を加えて、Google検索URLの検索クエリへ設定し、外部ブラウザで開くことにより行われます。URLに収まらない長さの場合は、依頼文をクリップボードにコピーし、ユーザーが検索欄へ貼り付けます。検索内容は、ブラウザ履歴またはログイン中のGoogleアカウントの検索履歴に保存される場合があります。

本アプリは、送信のたびに、送信するデータ、送信先（Google LLC）、目的、および履歴に残る可能性をアプリ内で説明し、ユーザーが「同意してGoogleへ送信」を選択した場合にのみ送信します。キャンセルした場合、Googleへの送信およびクリップボードへの書き込みは行いません。

Googleの回答は、ユーザーがコピーしてアプリに戻った場合に限り、取り込みのためクリップボードを読み取り、端末内に保存します。読み取った内容を本アプリが別の外部サービスへ送信することはありません。

Googleに送信されたデータの利用、保持、削除は [Googleプライバシーポリシー](https://policies.google.com/privacy) およびユーザーのGoogleアカウント設定に従います。

## 4. Google AIによる固定プロンプトの生成

問題文の追加、発音課題の追加、および語彙の追加（ユーザーが選んだJLPTレベルの指定のみ）の機能では、アプリがあらかじめ用意した固定プロンプトだけをGoogle検索（AIモード）へ送信します。この固定プロンプトには、録音、文字起こしその他のユーザーデータは含まれません。ユーザーがGoogleの回答をコピーした場合、本アプリは取り込みのためクリップボードを読み取ります。読み取った内容を本アプリが別の外部サービスへ送信することはありません。

## 5. Podcastおよび外部コンテンツ

Podcast検索では検索語をApple Inc.のiTunes Search APIへ送信します。登録したPodcastを更新・再生する際は、Podcast配信元へ直接接続します。接続先ではIPアドレス、アクセス日時、要求したコンテンツ等が通信ログとして処理される場合があります。

## 6. 端末内での保存と保持期間

文字起こし、採点結果、発音評価、AI回答、単語帳、Podcast情報、設定等は端末内に保存されます。開発者がこれらの内容へ遠隔からアクセスすることはありません。

- 録音ファイル：直近の録音を固定ファイルとして保持し、次の録音で上書きします。練習のリセットまたは全データ初期化で削除します。
- 採点・発音チェック履歴：ユーザーが削除するか、アプリを削除するまで保持します。
- 音声認識診断ログ：端末内に最大200件保持します。

ユーザーは履歴の個別削除、評価結果の一括削除、または「設定 > すべてのデータを初期化」により、端末内データと録音ファイルを削除できます。

## 7. バックアップと共有

ユーザーがエクスポートを実行した場合、端末内データをJSONファイルとして作成し、OSの共有シートへ渡します。共有先はユーザーが選択します。

iPhoneで「設定 > iCloud同期」をオンにした場合に限り、文字起こし、採点結果、単語帳、問題文、Podcastの番組とエピソード（再生位置・再生済み等）、設定等を、ユーザー自身のiCloud（Apple Inc.のiCloudキー値ストレージ）に保存し、同じApple IDの端末どうしで同期します。表示言語、案内画面の表示、音声送信の同意、録音ファイルは同期しません。同期データはユーザーのiCloudアカウント内にあり、開発者はアクセスしません。オフにすると以後の送受信を行いません。

iCloud等の端末バックアップを有効にしている場合、OSの機能によりアプリデータがクラウドへ保存されることがあります。開発者はこれらのバックアップへアクセスしません。

## 8. 第三者による保護

本アプリは、ユーザーへの事前説明と同意なしに個人データを第三者へ送信しません。利用する第三者サービスについて、公開されたプライバシー方針およびセキュリティ対策を確認し、本ポリシーと同等以上の保護を提供するサービスに限定します。各第三者は、そのプライバシーポリシーおよび適用法令に従ってデータを保護します。

本アプリは第三者サービスの認証情報やデータへアクセスせず、広告目的の販売または共有を行いません。

## 9. 同意の撤回と第三者側のデータ削除

音声認識への同意は「設定 > プライバシーとデータ」から撤回できます。撤回後は、次回利用時に再度同意を求めます。

すでにApple、GoogleまたはAndroidの音声認識事業者へ送信されたデータの削除は、各事業者のプライバシー管理画面または問い合わせ窓口をご利用ください。Google検索履歴はGoogleアカウントの「マイ アクティビティ」から管理できます。
