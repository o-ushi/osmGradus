## 4️⃣ その他

**修正済み（バグ発見）：** ランダム画面で解答例の「貼り付け待ち
（`chromeAiAwaitingPaste == true`）」中に、以下いずれかの操作を行うと、
表示中の問題文だけが切り替わり、貼り付け待ち状態（＝次のタップを
「送信」ではなく「貼り付け」として扱う内部フラグ）が古い問題文のまま
残ってしまうことを発見した。

- リセット（`_resetPrompt`）
- カテゴリ変更（`CategorySelectField.onChanged`）
- サイコロでの再抽選（`_drawPrompt`）

この状態で新しい問題文の解答例アイコンをタップすると、本来は「未取得
→送信」が期待される場面で、クリップボードの中身（古い問題文向けに送信した
プロンプト文、またはその後Chromeでコピーされた無関係な文字列）を新しい
問題文の`sampleAnswer`として誤って保存してしまう可能性があった
（実UIの見た目＝送信前のアイコン と 内部状態＝貼り付け待ち が食い違う
ケース）。

レイヤーⅠ語彙テスト画面（`layer1_vocab_screen.dart`の`_resetAttempt`）が
リセット時に`chromeAiAwaitingPaste = false`等を明示的にクリアしている
既存パターンに倣い、`layer2_random_screen.dart`の3箇所
（`_resetPrompt`・カテゴリ変更・`_drawPrompt`）で`chromeAiAwaitingPaste`が
trueなら`clearChromeAiPendingState()`を呼ぶよう修正した。

修正前は再現する回帰テストが赤くなることを確認した上で反映：
`test/question_prompt_layer2_test.dart`に
「ランダム：解答例の貼り付け待ち中にリセット・再抽選すると、貼り付け待ち
状態も解除される」を追加。
