# 解答例：末尾の提案文を消す＋日本語の下にローマ字、ローマ字の下にベトナム語訳

このファイルは Claude Code 向けの実装指示書です。  
ユーザーは次のように指示します。

> `docs/prompts/sample-answer-romaji-vietnamese.md` のステップに沿って実装して

Step 1 から順に全部やる。1 Step 終わったら `flutter analyze`（またはその Step のテスト）で破綻がないことを確認してから次へ進む。  
1 Step だけ頼まれたときは、その Step の「指示」と「受け入れ」だけをやる。

```
docs/prompts/sample-answer-romaji-vietnamese.md の Step 1 をやって
```

**前提（実装済み）:** レイヤーⅡ・Ⅳの「解答例」は Chrome AI 往復で取得し、`QuestionPrompt.sampleAnswer` にプレーンテキストで保存する。依頼文は `Layer2SampleAnswerAiPromptTemplate`。表示は `showSampleAnswerReadOnlySheet`（`TextViewSheet`、見出し付きテキストをそのまま見せる）。ⅡとⅣは `Layer2SampleAnswerMixin` を共有する。

現状の返答形式は次の3ブロック。

```
[質問]
{問題文}
[日本語]
{約45秒の口語の模範解答}
[Romaji]
{その日本語のローマ字}
```

---

## 機能概要（ユーザーの狙い）

実機の「解答例」シートで、ローマ字のあとに次のような一文が付いていた（添付スクリーンショット）。これは模範解答ではない。

> この模範解答のスピード調整や、よりフォーマルなビジネス表現への変更など、さらに練習しやすいようにカスタマイズしましょうか？

やること:

1. **模範解答を作るとき、この種の追記を入れない。** スピード調整・フォーマル／ビジネス表現への変更・「カスタマイズしましょうか」などの続きの提案・質問は書かない。
2. **日本語の模範解答の直下に、そのローマ字を置く。** ローマ字だけを返して日本語本文を省かない。
3. **そのローマ字の直下に、ベトナム語訳を置く。** 訳は `[日本語]` の意味を伝える正確なベトナム語（話し言葉の模範解答をもう一つ作るのではない）。

保存・表示する形（見出しは半角ブラケット。この表記のまま。翻訳しない）:

```
[質問]
{問題文。状況条件があればそれも含める}
[日本語]
{口語・自然な話し言葉の模範解答（約45秒）。かな・漢字の日本語。ローマ字にしない}
[Romaji]
{直上の [日本語] のローマ字。ヘボン式寄り・読みやすさ優先。長音は一般的な表記でよい}
[ベトナム語]
{直上の [日本語] のベトナム語訳}
```

最後のブロックのあとには何も書かない。

**対象外（触らない）:**

| 項目 | 理由 |
|------|------|
| 解答例ボタンの位置・アイコン・同意ダイアログ・長押し再取得 | 動線は変えない |
| レイヤーⅣのタイマー／録音／JSST／PREP・的中度 | 解答例テキストの中身だけ |
| `sampleAnswer` を JSON に分割 | いまどおり1文字列 |
| シートタイトル「解答例」や新規の画面文言 | 見出しは解答テキスト側。l10n を増やさない |
| ヘルプ文の書き換え | ブロック構成をユーザー向けヘルプでは説明していない |

---

## 共通ルール（全 Step 共通・必ず守る）

1. **ⅡとⅣの両方に効かせる。** 依頼文は共通テンプレ、保存前の整形と表示は `Layer2SampleAnswerMixin` / `showSampleAnswerReadOnlySheet`。画面ごとにコピペしない。
2. **旧データは落とさない。** 見出しなしの日本語だけ、および `[ベトナム語]` の無い3ブロックは、これまでどおり保存・表示できる。
3. **依頼文は短く足す。** `GoogleAiSearch.maxPrefillUrlLength`（7500）を超えるとクリップボード貼り付けに切り替わる。短い問題文が URL に載る既存テスト（`requiresClipboardPaste == false`）を壊さないこと。
4. **スコープ外を触らない。** その Step の受け入れ以外のリファクタや、このファイル以外のドキュメント追加はしない（Step 3 のレビュー文書だけ例外）。
5. **完了報告** — 変更ファイル一覧、確認したテスト、次 Step への前提を短く報告する。

## Step 1 — 依頼文を4ブロックにし、末尾の提案を禁止する

### 目的

Chrome AI への依頼を、`[質問]` → `[日本語]` → `[Romaji]` → `[ベトナム語]` の順に固定する。日本語の直下がローマ字、ローマ字の直下がベトナム語訳になるようにする。スクリーンショットのような続きの提案は書かせない。

### 指示

1. `lib/data/layer2_sample_answer_ai_prompt_template.dart` の ja / en / vi の `_copy` を更新する。
   - 見出しはこの4つをこの順。見出し文字列は依頼文の言語によらず `[質問]` `[日本語]` `[Romaji]` `[ベトナム語]` のまま。
   - `[日本語]` は約45秒の口語。かな・漢字で書く。ローマ字だけで置き換えない。「結論：」などのラベルは付けない（現行方針を維持）。
   - `[Romaji]` は直前の `[日本語]` の書き起こし。
   - `[ベトナム語]` は直前の `[日本語]` のベトナム語訳。意味が伝わる訳であり、ベトナム語のスピーキング原稿ではない。
   - 前置き・依頼文の繰り返しに加え、**最後のブロックのあとの追記を禁止**する。次を例として明示してよい（依頼文が膨らみすぎない範囲で、3言語とも同じ禁止）:
     - スピードを調整するか
     - よりフォーマルなビジネス表現に変えるか
     - 「カスタマイズしましょうか」と続けるか
   - 返すのはプレーンテキストのみ（JSON・Markdown 見出しなし）。
2. ファイル先頭コメントの「3ブロック」を4ブロックの説明に更新する。
3. `test/layer2_sample_answer_ai_prompt_template_test.dart` を追従する。
   - ja / en / vi の依頼文に4見出しが含まれる。
   - 出現順は `[質問]` → `[日本語]` → `[Romaji]` → `[ベトナム語]`。
   - 末尾に何も書かない／カスタマイズの提案をしない、という禁止が3言語にある（各言語の依頼文に、その禁止だと分かる短い語句があればよい）。
   - 「短い依頼は URL に載せる」テストは維持する。指示を足した結果 `requiresClipboardPaste` が true になるなら、禁止文を短くして URL 経路に戻す。

### 受け入れ

- [ ] 3言語の依頼文が4ブロックをこの順で要求している
- [ ] 3言語とも、末尾の調整・カスタマイズ提案を書くなと指示している
- [ ] `[日本語]` をローマ字で代用しない旨がある
- [ ] テンプレテストが緑
- [ ] 短い問題文の `buildLaunchPlan` はこれまでどおり URL 直開き（`requiresClipboardPaste == false`）

### 手動確認

- なし（実機の再取得は Step 2 のあとでよい）

## Step 2 — 付いてしまった提案文を保存前と表示前に落とす

### 目的

依頼文で禁止しても、Chrome 側がスクリーンショットのような一文を足すことがある。保存する文字列と、解答例シートに出す文字列から、その末尾の提案だけを除く。模範解答の本文（日本語が疑問文で終わる場合を含む）は残す。

すでに保存済みの解答例も、シートを開いたときに同じ除去が効くこと（保存データの書き換えは、表示のためには不要。新規の貼り付け時だけ保存前に除く）。

### 指示

1. `lib/services/layer2_sample_answer_chrome_ai.dart` に、テストから呼べる純関数を置く（例: `stripSampleAnswerFollowUp`）。入力の解答テキストから、末尾の「続きの提案」段落だけを除いて返す。
2. 除く対象は、**末尾の1段落**（空行で区切られた最後の塊。空行が無ければ、本文のあとに続く最後の質問文）で、次のどれかに当たるもの。
   - スクリーンショットの文そのもの、および同じ申し出の言い換え（スピード調整、フォーマルな表現への変更、「カスタマイズしましょうか」）
   - 疑問文（末尾が `？` または `?`）であり、かつ模範解答の手直しを申し出ている（カスタマイズ／調整／フォーマル／スピード、または英語の customize・adjust the sample、ベトナム語の tùy chỉnh など）
3. 除かないもの:
   - `[日本語]` ブロックの中にある発話そのもの（疑問文で終わってよい）
   - 見出し行 `[質問]` `[日本語]` `[Romaji]` `[ベトナム語]`
   - 提案段落が無いテキスト（そのまま返す）
4. 見出しが付いているときは、最後の見出しブロックの本文の末尾からだけ除く。前のブロックには触らない。
5. 見出しが無い旧テキストでも、末尾段落が上記の提案なら、その段落だけ除く。
6. 呼び出す場所:
   - 自動貼り付けで `saveSampleAnswer` する直前
   - 手動貼り付けシートで保存する直前
   - `showSampleAnswerReadOnlySheet` で `TextViewSheet` に渡す直前（保存済みの古い文もシート上では出さない）
7. 除去した結果が空、またはこれまでの妥当性チェックに落ちる場合は保存しない（既存の失敗扱い）。
8. `isPlausibleSampleAnswer` / `isAcceptableManualPaste` は4ブロック全文を通す。3ブロックと、見出しなしの日本語本文もこれまでどおり通す。依頼文マーカーを足す場合は、解答本文に普通に出うる語（「カスタマイズ」単体など）をマーカーにしない。依頼文のエコーを弾く既存方針だけ維持する。
9. `test/chrome_ai_round_trip_test.dart` に追加する。
   - 4ブロック全文はそのまま通る（plausible / 手動貼り付け）
   - `[ベトナム語]` のあとにスクリーンショットの文が付いたテキストは、除去後その文を含まない。`[日本語]` `[Romaji]` `[ベトナム語]` の本文は残る
   - `[日本語]` が疑問文で終わる模範解答は、その疑問文が残る
   - 提案の無い3ブロック・見出しなし本文は変化しない
   - 既存の「3ブロックは通す」テストは、4ブロックを追加したうえで残してよい（旧形式を拒否しない）

### 受け入れ

- [ ] 新規保存時に、末尾のカスタマイズ提案が `sampleAnswer` に入らない
- [ ] すでにその文が入っている解答例を開いても、シート本文には出ない
- [ ] 日本語の疑問文や、提案の無い旧解答は欠けない
- [ ] 4ブロック・3ブロック・見出しなしが妥当性チェックを通る
- [ ] 関連テストと `flutter analyze` が緑

### 手動確認

1. レイヤーⅡ（一覧またはランダム）で解答例を再取得する
2. コピーして戻し、シートを開く
3. 並びが `[質問]`、`[日本語]`、その下に `[Romaji]`、その下に `[ベトナム語]` である
4. 末尾に「カスタマイズしましょうか」の類が無い
5. 取得済みの古い解答例を開いても、同じ類の末尾文が出ない（本文は残る）
6. レイヤーⅣの解答例ボタンでも、同じシートの中身になる（ボタンの位置や採点の動線は以前と同じ）

## Step 3 — レビュー（重複・ゾンビ・冗長・その他）

### 目的

Step 1〜2 のあと、次の4観点だけ点検し、明らかな問題を直す。

### 観点

1. **作成者の意図に反して重複している機能**  
   ⅡとⅣで除去処理を別実装していないか。依頼文をテンプレ以外にも書いていないか。  
   ※ⅡとⅣが同じ mixin・同じテンプレを使うのは意図どおり（重複扱いしない）。

2. **ゾンビ化している機能**  
   「3ブロックだけ」と書いたコメントが実装と食い違っていないか。使っていない関数、死んだテスト名。

3. **作成者の意図に反して動線が冗長的な機能**  
   ベトナム語訳のために新しい画面・確認ダイアログ・ボタンを足していないか。

4. **その他**  
   日本語の疑問文まで消している。旧3ブロックや見出しなしが保存・表示できない。ja の依頼文だけ更新して en / vi が旧形式のまま。短い問題文がクリップボード貼り付けに落ちた。除去が `[日本語]` 本文の途中まで削る。

### 指示

1. Step 1〜2 のコードを上記で点検する
2. 明らかで安全な修正は同じ作業で直す。設計を広げる変更は提案だけにする
3. 結果を `docs/prompts/sample-answer-romaji-vietnamese-review.md` に短く書く（各項目は **修正済 / 意図的残置 / 提案のみ**）
4. `flutter analyze` と、Step 1〜2 で触ったテストを通す

### 受け入れ

- [ ] レビュー文書がある
- [ ] 致命的な重複・ゾンビ・余分な画面・旧解答が読めない状態が残っていない（残すなら意図的残置の理由がある）

## 設計メモ

| 現状 | 本改修 |
|------|--------|
| `[質問]` / `[日本語]` / `[Romaji]` | その後に `[ベトナム語]`（`[日本語]` の訳） |
| ローマ字のあとに、速度や表現の変更を提案する文が付くことがある | 依頼文で禁止し、付いた場合は保存前と表示前に末尾段落だけ除く |
| モデルがローマ字だけ返すことがある | `[日本語]` はかな・漢字。ローマ字はその直下の別ブロック |

ユーザー原文の「ベトナム誤訳」は「ベトナム語訳」として扱う。誤った訳を意図的に出す仕様ではない。
